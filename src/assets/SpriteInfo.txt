# Как устроены иконки зданий:
# 1. Файл лежит в src/assets/buildings/<slug>.svg (или .webp/.png). Имя файла = slug здания.
# 2. index.js подхватывает файлы автоматически, править его не нужно. При совпадении имён .svg важнее.
# 3. Нижний угол ромба основания = нижний край картинки, ширина картинки = ширина ромба w×h клеток.
#    Тогда на карте здание встаёт ровно на свои клетки. Без картинки рисуется цветной блок с подписью.
# 4. Стандартные рисунки — src/features/farm/buildingArt/classic.js, модульная генерация — procedural.js.
#    Стандартные SVG в этой папке сохраняет скрипт:  node tools/gen_buildings.mjs
# 5. Игрок может сменить внешний вид типа здания (окно «🎨 Внешний вид», 500 монет): вариант рисуется
#    в браузере тем же кодом по трём зёрнам (цвета, крыша, детали), зёрна хранятся на сервере.
